# Wispa — instaladores

Dictado por voz con IA para Windows: dicta, traduce, crea prompts y toma notas de reuniones.

Este repositorio solo contiene los **instaladores**. Las copias instaladas de Wispa comprueban aquí si hay versiones nuevas y se actualizan solas.

## Instalar
1. Descarga `Wispa-Setup-<versión>.exe` desde la [última versión](https://github.com/Reynellmds/wispa-releases/releases/latest).
2. Si Windows muestra "Windows protegió tu PC" (el instalador no está firmado): **Más información → Ejecutar de todas formas**.
3. Abre Wispa, entra con tu correo y, en **Configuración → Claves de API**, pega tus claves de Groq y Anthropic.

Las actualizaciones posteriores se descargan e instalan solas.
