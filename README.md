# Wispaflou — instaladores

Dictado por voz con IA para Windows: dicta, traduce, crea prompts y toma notas de reuniones.

Este repositorio solo contiene los **instaladores**. Las copias instaladas de Wispaflou comprueban aquí si hay versiones nuevas y se actualizan solas.

## Instalar
1. Ve a [Releases](https://github.com/Reynellmds/wispaflou-releases/releases/latest) y descarga `Wispaflou-Setup-<versión>.exe`.
2. Si Windows muestra "Windows protegió tu PC" (el instalador no está firmado): **Más información → Ejecutar de todas formas**.
3. Abre Wispaflou → **Configuración → Claves de API** y pega tus claves de Groq y Anthropic.

Las actualizaciones posteriores se descargan e instalan solas.
